# VDS - Veltrix Digital Studio

Premium scroll-animation website for Veltrix Digital Studio.

## Features
- 240-frame scroll-driven animation intro
- Responsive design
- Portfolio showcase
- Contact form
- WhatsApp integration

## Deploy on Vercel
1. Push to GitHub
2. Import the repo in [Vercel](https://vercel.com)
3. Deploy — no build step needed (static site)

## Local Development
Open `index.html` directly or serve with any static server.
